# Análise e Desenvolvimento de Sistemas – FATEC Lins

O objetivo deste repositório é armazenar e organizar os materiais produzidos durante os semestres do curso de Análise e Desenvolvimento de Sistemas, facilitando o acesso aos documentos acadêmicos e mantendo um histórico das atividades realizadas.

## Engenharia de Software I

Nesta matéria foram desenvolvidos documentos relacionados à análise de sistemas, estudo de caso, ciclo de vida do software, levantamento de requisitos funcionais e não funcionais e documentação de casos de uso.

O foco principal foi compreender as etapas de planejamento e desenvolvimento de um sistema, utilizando como projeto um Sistema Web para Gestão de Academia.

### Arquivos

- `documentação - engenharia de software I.docx`

### O que foi feito

- Elaboração de estudo de caso para um sistema de gestão de academia.
- Estudo do ciclo de vida do software.
- Levantamento de requisitos funcionais e não funcionais.
- Identificação dos usuários e funcionalidades do sistema.
- Documentação e organização dos casos de uso.
- Definição de regras de negócio e características do sistema.

## Projeto Integrador I

Nesta matéria foram desenvolvidos uma pesquisa comparativa e um pitch de apresentação sobre um Sistema Web para Gestão de Academia.

O objetivo foi analisar soluções existentes no mercado, identificar suas funcionalidades, vantagens e limitações e utilizar essas informações para propor um sistema voltado à organização e administração de academias.

### Arquivos

- `Relatorio_Pesquisa_Sistemas_Academia-1.docx`
- `Pitch_Academia.pptx`

### O que foi feito

- Pesquisa sobre os sistemas Pacto, Tecnofit e EVO/W12.
- Comparação das funcionalidades oferecidas pelas plataformas.
- Análise dos modelos de comercialização e tecnologias utilizadas.
- Identificação de vantagens, limitações e oportunidades de melhoria.
- Definição das principais funcionalidades do sistema proposto.
- Elaboração de um pitch para apresentação da solução.

## Sistemas Operacionais

Nesta matéria foram realizadas atividades relacionadas ao funcionamento dos sistemas operacionais, gerenciamento de arquivos, comandos Linux, permissões de acesso e organização de diretórios.

Também foram desenvolvidas pesquisas sobre supercomputadores e métodos de ensino de Sistemas Operacionais, relacionando os conceitos teóricos com aplicações práticas.

### Arquivos

- `MICROSOFT-EAGLE.pdf`
- `Atividade de Pesquisa Científica - Artigo 5.docx`
- `Lista de Exercícios 1 - Resolução.png`
- `Lista de Exercícios 2 - Resolução.docx`
- `Lista de Exercícios 3 - Resolução.docx`

### O que foi feito

- Estudo da estrutura de diretórios do Linux.
- Utilização de comandos para criação, cópia, movimentação e exclusão de arquivos e pastas.
- Prática com caminhos absolutos e relativos.
- Gerenciamento de permissões com `chmod`, `chown` e `umask`.
- Utilização de comandos como `ls`, `cd`, `pwd`, `mkdir`, `cp`, `mv`, `rm`, `find`, `grep`, `sort`, `head`, `tail` e `wc`.
- Resolução de exercícios práticos utilizando o terminal Linux.
- Pesquisa sobre o supercomputador Microsoft Eagle, sua arquitetura, componentes e desempenho.
- Análise de artigo científico sobre métodos de ensino e aprendizagem de Sistemas Operacionais.
